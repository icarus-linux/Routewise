ROUTEWISE QUICK GUIDE

Purpose
Routewise is a browser-based fleet and operations management project. It is currently an early static HTML prototype intended to establish the page structure and user workflows.

Current Pages
- src/index.html: demo login page. The Login link opens the general-user dashboard without checking credentials.
- src/generaluser/dashboard.html: general-user dashboard overview.
- src/generaluser/fleet.html: fleet and item list placeholder.
- src/generaluser/routes.html and create_route.html: route list and route form placeholders.
- src/generaluser/maintenance.html, log_problem.html, and logs.html: maintenance overview, issue report form, and issue history placeholders.
- src/generaluser/tokens.html: read-only token activity placeholder.
- src/Admin/admin_dashboard.html: company-admin overview and links.
- src/Admin/user_overviews.html and create_new_user.html: company user list and creation form placeholders.
- src/Admin/token_management.html: company token purchase and balance placeholder.
- src/Admin/activity_logs.html and company_settings.html: company activity and settings placeholders.

Intended Roles
- General users handle everyday fleet, route, and issue workflows. They may view token information but cannot purchase tokens or manage company users.
- Company admins manage users, company settings, token purchases, and company records.
- The current HTML prototype does not enforce these roles or permissions.

Current Limitations
The pages contain static markup only. Forms do not create or save records, tables do not load company data, and login, token purchases, and access control are not connected to a backend. Empty tables and unavailable values are expected.

Project Folders
- src/: application pages
- src/generaluser/: general-user pages
- src/Admin/: company-admin pages
- assets/: logos and visual assets
- docs/: project documentation
- docs/guides/: user and troubleshooting guides

Preview
Open src/index.html in a browser. To inspect the company-admin area, open src/Admin/admin_dashboard.html directly. The login page currently routes only to the general-user dashboard.

Project direction
Routewise aims to become a clear, affordable tool for company fleet operations. Support services, live data, payments, and production-ready account security are future work, not features of the current prototype.
