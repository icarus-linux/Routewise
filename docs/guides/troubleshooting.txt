# Routewise Troubleshooting Guide

The current Routewise pages are static HTML prototypes with table-based navigation and placeholders. The following behavior is expected until authentication and data storage are implemented.

## Common Issues

### Login does not check my credentials
The Login control is a link to the general-user dashboard. It does not authenticate or validate the username and password fields.

### Admin pages do not appear after login
The demo login always opens the general-user dashboard. To preview the company-admin pages, open src/Admin/admin_dashboard.html directly.

### Tables are empty
The tables are placeholders and are not connected to a database or sample data source. Empty-state messages are expected.

### Create or report pages have no fields
The create-route, report-problem, and create-user pages currently display placeholders only. Input and submission workflows have not been implemented.

### Token balance or purchase information is unavailable
Token balances and purchases are not implemented. General-user token information is planned as read-only; company-admin purchasing is a placeholder.

### A page link does not open
Keep the existing directory structure so relative links work. General-user files belong in src/generaluser/ and company-admin files belong in src/Admin/. Each table navbar only links to pages in its own role folder.

### The page looks unstyled or the logo is missing
The HTML pages load their shared stylesheet from src/styles/styles.css and the logo from assets/logo/routewise-logo-kit/routewise-icon.svg. Keep those paths and folders intact, and avoid separating an HTML file from its assets. Reload the page after restoring a missing file.

### The dashboard tiles or tables look crowded on a small screen
The dashboard grid becomes a single column on narrow screens. Wide tables can scroll within their content area; swipe or scroll horizontally over the table to see additional columns.

## Preview Checklist

- Open src/index.html in a browser.
- Confirm the expected HTML file exists at the linked path.
- Keep the src/generaluser/ and src/Admin/ folder names and capitalization unchanged.
- Keep src/styles/styles.css and assets/logo/routewise-logo-kit/ in their original locations.
- Remember that tables are not connected to persistent data and create/report pages are placeholders.

## Security Note

The prototype does not protect admin pages or enforce user roles. Separate navbar links are not security controls; any page may be opened directly by URL. Do not use it to manage real users, payments, or sensitive company data. Authentication and server-side authorization must be implemented before deployment.

For more information, see user-guide.txt and docs/Documentation.txt.
