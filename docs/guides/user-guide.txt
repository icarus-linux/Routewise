# Routewise User Guide

## Current Version

This guide describes the static HTML prototype. Pages show planned workflows using tables and placeholders; they do not load or save real company data.

## Preview the General-User Pages

1. Open src/index.html in a web browser.
2. Entering credentials is optional; the fields are not validated.
3. Select Login. The link opens src/generaluser/dashboard.html for every visitor.
4. Use the navbar at the top of each page to open other General User pages. Its links stay within src/generaluser/. The current page is highlighted.

## Preview the Company-Admin Pages

Open src/Admin/admin_dashboard.html directly. The navbar at the top of each Admin page links to the other Admin pages and stays within src/Admin/. The current page is highlighted.

## Appearance and Layout

Pages share the Routewise brand styling: a navy-and-teal palette, the Routewise icon beside page titles, and light bordered content tiles. The General User and Company Admin dashboards show overview sections in a responsive tile grid. On narrow screens, dashboard tiles stack vertically and wide tables can scroll horizontally.

The stylesheet is src/styles/styles.css. The logo is loaded from assets/logo/routewise-logo-kit/routewise-icon.svg. Keep these paths and folders in place when previewing or copying the pages.

## Page Guide

- Dashboard: overview tables for fleet/items, maintenance, tokens, activity, and team access.
- Fleet: planned list of company trucks and tracked items.
- Routes: planned route list.
- Create Route: placeholder; route creation is not available yet.
- Maintenance and Issues: planned maintenance and issue overview.
- Report a Problem: placeholder; problem reporting is not available yet.
- Issue and Maintenance Logs: planned history of reported issues and service records.
- Token Balance: general users can view token activity; purchasing is reserved for company admins.
- Company Admin Dashboard: company summary and links to admin tools.
- Company Users: planned user list.
- Create User: placeholder; user creation is not available yet.
- Token Management: planned company token balance and purchase history.
- Company Activity: planned company-wide activity history.
- Company Settings: placeholder for company details and preferences.

## Important Limitations

- Create-user, create-route, and report-problem pages are placeholders with no input controls.
- Table-navbar links navigate between pages but do not enforce role permissions. A page can still be opened directly by URL.
- Empty tables and unavailable values are expected until a data source is added.
- The demo login does not authenticate users or choose a page based on role.
- Admin pages are not access-controlled. Do not use the prototype with sensitive or real company data.
